📋 Exact Steps for Each Source
1. iNaturalist → inaturalist.org

Search species name → click Sounds tab → filter by India → download MP3s

2. Xeno-canto → xeno-canto.org

Search scientific name → filter by Amphibians → download WAV/MP3 free

3. Mandookavani → gubbilabs.in

Email: gururaja@gubbilabs.in
Say you're doing an ML research project on Western Ghats frogs — they share data for research

4. AmphibiaWeb → amphibiaweb.org/lists/sound.shtml

Has 823 sound files in MP3, WAV and RM formats AmphibiaWeb — search each species name

5. YouTube extraction — for calls posted as videos:
pip install yt-dlp
yt-dlp --extract-audio --audio-format wav "youtube_url"

🔑 Most Important Tip
For Rhacophorus malabaricus specifically — males call from stream banks during monsoon months June–September Wikimedia — so most recordings online will be from that season. Search iNaturalist filtering by sound + Karnataka/Kerala + June–September for best results.
